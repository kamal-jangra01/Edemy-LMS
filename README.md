# 🎓 Edemy LMS - A Modern Learning Management System

**Edemy LMS** is a comprehensive, full-stack Learning Management System that connects educators and students through a seamless, interactive platform. Powered by **Clerk** for secure authentication and **Stripe** for reliable payments, it allows educators to use a dedicated dashboard to create courses, manage content, and track enrolled students. For learners, the platform offers robust discovery features, including course search, free lecture previews, and a rating system. Upon purchasing a course, students gain full, lifetime access in their "My Enrollments" section, which features advanced progress tracking to monitor exactly how many lectures they have watched and their overall completion percentage.

## 🛠️ Tech Stack & Deployment

**🖥️ Frontend**
* **Framework:** React 19 bootstrapped with Vite 8
* **Styling:** Tailwind CSS & Autoprefixer
* **Routing & Requests:** React Router DOM, Axios
* **Key Integrations:** `@clerk/react` (Auth), `quill` (Rich Text Editor), `react-youtube`, `rc-progress` (Progress bars)

**⚙️ Backend**
* **Runtime:** Node.js & Express 5
* **Payments & Events:** Stripe API, Svix (Webhooks)
* **Media Handling:** Cloudinary, Multer
* **Security:** `@clerk/express`, CORS, Dotenv

**🗄️ Database & ☁️ Deployment**
* **Database:** MongoDB configured with Mongoose (NoSQL)
* **Frontend Hosting:** Vercel
* **Backend Hosting:** Render
* **Media Storage:** Cloudinary

## ✨ Key Features

### 👨‍🎓 For Students
* **Course Discovery:** Easily search and browse the complete course catalog.
* **Free Previews:** Watch introductory preview lectures to evaluate content before buying.
* **Secure Purchases:** Checkout instantly and securely using Stripe. 
* **My Enrollments:** A dedicated space for all purchased courses with lifetime access.
* **Advanced Progress Tracking:** Real-time stats showing the exact percentage of the course completed and the number of lectures watched.
* **Course Ratings:** Share feedback by providing star ratings on completed courses.

### 👨‍🏫 For Educators
* **Educator Dashboard:** A centralized interface to create, upload, and manage course content effortlessly.
* **Enrollment Insights:** View a detailed list of all students who have enrolled in your courses and track your sales.
